## Hardening (Task 1)
- Centralized AFL-only scope/injection gate runs before retrieval or prediction.
- Every tool/model call (`retrieval`, `predict_match`, `predict_top_player`) is wrapped
  with a hard `TOOL_TIMEOUT_SECONDS` timeout in `app/core.py`, so a slow/stuck call
  degrades to a clear message instead of hanging the request.
- The API applies a simple in-memory sliding-window rate limit per client IP
  (`app/api.py`), and the core graph tracks repeated off-topic/injection "strikes"
  per `conversation_id` within a rolling window and flags them in the logs.
- One centralized prediction disclaimer string (`PREDICTION_DISCLAIMER`) is reused
  everywhere a probability is surfaced.

The supplied AFL data ends on 2025-09-27. The system does not invent 2026 fixtures; a production current/upcoming fixture source is required.
